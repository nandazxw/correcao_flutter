ATIVIDADE PRÁTICA – CORREÇÃO DE PROJETO FLUTTER
Turma: 2º C

CENÁRIO
Você recebeu de outro desenvolvedor um aplicativo chamado "Portal do Aluno".
O projeto possui 5 telas funcionais planejadas, porém o código contém diversos
erros de sintaxe, estrutura, tipos, layout, estilização e navegação.

OBJETIVO
Corrigir o projeto até que ele execute corretamente e apresente uma interface
organizada e coerente com os conceitos estudados em Flutter.

TELAS DO PROJETO
1. Login
2. Página Inicial
3. Perfil
4. Cursos
5. Configurações

REGRAS
- Não apagar uma tela para fazer o projeto funcionar.
- Não substituir todo o projeto por um novo.
- Corrigir os erros existentes.
- Manter a navegação entre as 5 telas.


ENTREGA
1. Projeto Flutter corrigido.
2. Aplicativo executando.
3. Um arquivo RESPOSTAS.txt contendo:
   - Nome do aluno;
   - Quantidade de erros encontrados;
   - Lista dos erros identificados;
   - Como cada erro foi corrigido.

DESAFIO
Além dos erros que impedem a compilação, existem decisões de layout que podem
gerar interfaces inadequadas ou overflow. O aluno também deve identificá-las.

IMPORTANTE
Os comentários "ERRO PROPOSITAL" não indicam todos os problemas do projeto.
Existem outros erros que devem ser encontrados pela análise do código.
